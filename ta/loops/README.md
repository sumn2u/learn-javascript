# அத்தியாயம் 7
# சுழல்கள் (Loops)

சுழல்கள் என்பது மீண்டும் மீண்டும் செய்யப்படும் வழிமுறைகளாகும், இதில் சுழற்சியில் உள்ள ஒரு மாறி மாறுகிறது. நீங்கள் அதே குறியீட்டை மீண்டும் மீண்டும் இயக்க விரும்பினால், ஒவ்வொரு முறையும் வெவ்வேறு மதிப்புடன் சுழல்கள் கைக்கு வரும்.

இப்படி எழுதுவதற்குப் பதிலாக:

```javascript
doThing(cars[0]);
doThing(cars[1]);
doThing(cars[2]);
doThing(cars[3]);
doThing(cars[4]);
```

நீங்கள் இப்படி எழுதலாம்:

```javascript
for (var i = 0; i < cars.length; i++) {
  doThing(cars[i]);
}
```
