# Do...While

`do...while` அறிக்கை, சோதனை நிபந்தனை தவறு என மதிப்பிடப்படும் வரை ஒரு குறிப்பிட்ட தொகுதி அறிக்கையை இயக்கும் ஒரு சுழற்சியை உருவாக்குகிறது. தொகுதியை இயக்கிய பின்னரே நிபந்தனை மதிப்பிடப்படுகிறது. `do... while` க்கான தொடரியல்:

```javascript
do {
  // அறிக்கை
} while (expression);
```

எடுத்துக்காட்டாக, `do...while` சுழற்சியைப் பயன்படுத்தி 10-க்கும் குறைவான எண்களை எவ்வாறு அச்சிடுவது என்று பார்ப்போம்:

```javascript
var i = 0;
do {
  document.write(i + " ");
  i++; // i ஐ 1 ஆல் அதிகரித்தல்
} while (i < 10);
```

> _**குறிப்பு**_: `i = i + 1` என்பதை `i++` என்று எழுதலாம்.
