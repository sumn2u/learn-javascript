# இணைத்தல் (Concatenate)

மேலும், எந்தவொரு அறிக்கையும் (statement) உண்மையா அல்லது இரண்டும் உண்மையா என்பதைச் சோதிக்க, "அல்லது (`or`)" அல்லது "மற்றும் (`and`)" அறிக்கைகளுடன் வெவ்வேறு நிபந்தனைகளை நீங்கள் இணைக்கலாம்.

ஜாவாஸ்கிரிப்டில் “or” என்பது `||` எனவும் “and” என்பது `&&` எனவும் எழுதப்படுகிறது.

x இன் மதிப்பு 10 க்கும் 20 க்கும் இடையில் உள்ளதா என்று சோதிக்க விரும்புகிறீர்கள் என்று வைத்துக்கொள்வோம். பின்வரும் நிபந்தனையுடன் நீங்கள் அதைச் செய்யலாம்:

```javascript
if (x > 10 && x < 20) {
    ...
}
```

country என்பது "England" அல்லது "Germany" ஆக இருப்பதை நீங்கள் உறுதிசெய்ய விரும்பினால், நீங்கள் பயன்படுத்துவது:

```javascript
if (country === "England" || country === "Germany") {
    ...
}
```

> **குறிப்பு**: எண்கள் மீதான செயல்பாடுகளைப் போலவே, அடைப்புக்குறிகளைப் பயன்படுத்தி (parenthesis) நிபந்தனைகளையும் தொகுக்கலாம் (grouped), எ.கா: `if ( (name === "John" || name === "Jennifer") && country === "France")`.
