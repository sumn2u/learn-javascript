# அத்தியாயம் 23
# வடிவமைப்பு முறைகள் (Design Patterns) 

வடிவமைப்பு முறைகள் (Design patterns) என்பவை மேம்பாட்டு செயல்பாட்டின் (development process) போது ஏற்படக்கூடிய பொதுவான நிரலாக்கச் சிக்கல்களைத் தீர்க்க நீங்கள் செயல்படுத்தக்கூடிய பொருள் சார்ந்த (object oriented) தீர்வுகளாகும். வடிவமைப்பு முறைகள் அல்காரிதம்களைப் (algorithms) போன்றது அல்ல, அவை ஒரு குறிப்பிட்ட வகையான சிக்கல்களைத் தீர்க்க நீங்கள் பயன்படுத்தக்கூடிய குறியீட்டுக் கருத்தாகும் (coding concept). 

எந்த ஒரு மொழிக்கும் தனித்துவமில்லாத பல்வேறு வடிவமைப்பு முறைகள் உள்ளன. இந்த அடிப்படைக் கருத்துக்களைப் பல்வேறு வகையான நிரலாக்க மொழிகளில் பயன்படுத்தலாம். இன்று, ஒவ்வொரு வடிவமைப்பு முறை மற்றும் ஜாவாஸ்கிரிப்டைப் பயன்படுத்தி அவற்றை எவ்வாறு செயல்படுத்துவது என்பது பற்றி அறிந்து கொள்வோம். வடிவமைப்பு முறைகளை மூன்று வகைகளில் ஒன்றாகப் பிரிக்கலாம்.
