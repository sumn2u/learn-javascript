# சாளரம் (Window)

`window` பொருளானது உலாவி சாளரத்தைக் குறிக்கிறது மற்றும் இது உலாவிகளால் ஆதரிக்கப்படுகிறது. குளோபல் மாறிகள், பொருள்கள் மற்றும் செயல்பாடுகளும் window பொருளின் ஒரு பகுதியாகும். 

குளோபல் **மாறிகள்** window பொருளின் **பண்புகள் (properties)** மற்றும் **செயல்பாடுகள்** அதன் **முறைகள் (methods)** ஆகும்.

திரைப் பண்புகளின் (screen properties) எடுத்துக்காட்டை எடுத்துக்கொள்வோம். இது உலாவி சாளரத்தின் அளவைத் தீர்மானிக்கப் பயன்படுகிறது மற்றும் பிக்சல்களில் (pixels) அளவிடப்படுகிறது.    

* `window.innerHeight` - உலாவி சாளரத்தின் உள் உயரம் (inner height)
* `window.innerWidth` - உலாவி சாளரத்தின் உள் அகலம் (inner width)

> _**குறிப்பு**_: `window.document` என்பது `document.location` ஐப் போன்றதே, ஏனெனில் ஆவணப் பொருள் மாதிரி (document object model - DOM) window பொருளின் ஒரு பகுதியாகும்.

window முறைகளுக்கான சில எடுத்துக்காட்டுகள்

* `window.open()` - ஒரு புதிய சாளரத்தைத் திறக்கிறது
* `window.close()` - தற்போதைய சாளரத்தை மூடுகிறது
* `window.moveTo()` - தற்போதைய சாளரத்தை நகர்த்துகிறது
* `window.resizeTo()` - தற்போதைய சாளரத்தின் அளவை மாற்றுகிறது
