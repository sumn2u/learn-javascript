# அத்தியாயம் 16
# உலாவி பொருள் மாதிரி (Browser Object Model - BOM)

உலாவி பொருள் மாதிரி (Browser object model) உலாவி சாளரத்துடன் தொடர்புகொள்ள நம்மை அனுமதிக்கிறது. `window` பொருள் உலாவியின் சாளரத்தைக் குறிக்கிறது மற்றும் இது அனைத்து உலாவிகளாலும் ஆதரிக்கப்படுகிறது.

பொருள் (Object) `window` என்பது உலாவியின் இயல்புநிலை பொருளாகும், எனவே நாம் `window` ஐக் குறிப்பிடலாம் அல்லது நேரடியாக அனைத்து செயல்பாடுகளையும் அழைக்கலாம்.

```javascript
window.alert("Learn JavaScript க்கு வரவேற்கிறோம்");  

alert("Learn JavaScript க்கு வரவேற்கிறோம்")
```

இந்த அத்தியாயத்தில், உலாவி பொருள் மாதிரியின் (browser object model) பல்வேறு பண்புகள் மற்றும் முறைகளைப் பற்றிப் பேசுவோம்.
