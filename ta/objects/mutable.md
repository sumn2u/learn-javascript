# Mutable (மாற்றக்கூடியது)

பொருள்களுக்கும் (objects) primitive மதிப்புகளுக்கும் உள்ள வித்தியாசம் என்னவென்றால், நாம் **பொருள்களை மாற்றலாம்**, அதே சமயம் primitive மதிப்புகள் **மாற்ற முடியாதவை (immutable)**.

எடுத்துக்காட்டாக:

```javascript
let myPrimitive = "முதல் மதிப்பு";
myPrimitive = "மற்றொரு மதிப்பு";
// myPrimitive இப்போது மற்றொரு சரத்தை சுட்டிக்காட்டுகிறது.
let myObject = { key: "முதல் மதிப்பு" };
myObject.key = "மற்றொரு மதிப்பு";
// myObject அதே பொருளை சுட்டிக்காட்டுகிறது.
```

Dot notation அல்லது square bracket notation ஐப் பயன்படுத்தி ஒரு பொருளின் பண்புகளை நீங்கள் **சேர்க்கலாம்**, **மாற்றலாம்** அல்லது **நீக்கலாம்**.

```javascript
let object = {};
object.foo = 'bar'; // 'foo' பண்பைச் சேர்
object['baz'] = 'qux'; // 'baz' பண்பைச் சேர்
object.foo = 'quux'; // 'foo' பண்பை மாற்று
delete object.baz; // 'baz' பண்பை நீக்கு
```

{% hint style="working" %}
Primitive மதிப்புகள் (எண்கள் மற்றும் சரங்கள் போன்றவை) மாற்ற முடியாதவை, அதே சமயம் பொருள்கள் (வரிசைகள் மற்றும் பொருள்கள் போன்றவை) மாற்றக்கூடியவை.
{% endhint %}
