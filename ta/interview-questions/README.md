# அத்தியாயம் 22
# நேர்காணல் கேள்விகள் (Interview questions)

ஜாவாஸ்கிரிப்ட் பற்றிய அவர்களின் புரிதலைப் பற்றி விண்ணப்பதாரரை (candidate) சிறப்பாகத் தயார்படுத்துவதற்கான பல்வேறு கேள்விகளை இந்த அத்தியாயம் விவாதிக்கிறது. இது மூன்று பகுதிகளாகப் பிரிக்கப்பட்டுள்ளது: அடிப்படை (basic), இடைநிலை (intermediate) மற்றும் மேம்பட்ட நிலை (advance level).
