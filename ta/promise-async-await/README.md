# அத்தியாயம் 18
# Promise, async/await

Promises இப்போது பெரும்பாலான நவீன API களால் பயன்படுத்தப்படுகின்றன. எனவே அவை எவ்வாறு செயல்படுகின்றன என்பதைப் புரிந்துகொள்வதும் குறியீட்டை மேம்படுத்த அவற்றை எவ்வாறு பயன்படுத்துவது என்பதை அறிவதும் முக்கியம். இந்த அத்தியாயத்தில், promises என்றால் என்ன மற்றும் ஒத்திசைவற்ற (asynchronous) செயல்பாடுகளில் அவற்றை எவ்வாறு பயன்படுத்துவது என்பதை விரிவாக வரையறுப்போம்.
