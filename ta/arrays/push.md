# Push

ஒரு வரிசையில் சில உருப்படிகளை push செய்து கடைசி குறியீட்டை புதிதாக சேர்க்கப்பட்ட உருப்படியாக ஆக்கலாம். இது ஒரு வரிசையின் நீளத்தை மாற்றி புதிய நீளத்தை திரும்பப் பெறுகிறது.

`push` பயன்படுத்துவதற்கான தொடரியல் இங்கே:

```c
array.push(element1[, ...[, elementN]]);
```

`element1, ..., elementN` வாதங்கள் வரிசையின் இறுதியில் சேர்க்கப்பட வேண்டிய உறுப்புகளை குறிக்கின்றன.

எடுத்துக்காட்டாக:

```javascript
let array = [1, 2, 3]; 
array.push(4); 

console.log(array); 

// Result: array = [1, 2, 3, 4]
```

முதலில் `Array.prototype.slice()` முறையைப் பயன்படுத்தி வரிசையாக மாற்றி array-like பொருளின் (arguments பொருள் அல்லது NodeList பொருள் போன்ற) இறுதியில் உறுப்புகளை சேர்க்கவும் `push` ஐப் பயன்படுத்தலாம்:

```javascript
function printArguments() {
  let args = Array.prototype.slice.call(arguments);
  args.push('d', 'e', 'f');
  console.log(args);
}

printArguments('a', 'b', 'c'); // Result: ["a", "b", "c", "d", "e", "f"]
```

> **குறிப்பு**: `push` முறை அசல் வரிசையை மாற்றுகிறது. இது புதிய வரிசையை உருவாக்காது.
