## கெட்டர்கள் மற்றும் செட்டர்கள் (Getters and Setters)

ECMAScript 5 (ES5 2009) கெட்டர் மற்றும் செட்டர்களை அறிமுகப்படுத்தியது.

ஜாவாஸ்கிரிப்டில், கெட்டர்கள் மற்றும் செட்டர்கள் என்பவை பண்புகளுக்கான (properties) மதிப்பைப் பெற (get) அல்லது அமைக்கப் (set) பயன்படுத்தப்படும் முறைகள் (methods) ஆகும். கெட்டர்கள் மற்றும் செட்டர்களைப் பயன்படுத்தும்போது, நீங்கள் சிறந்த தரவுத் தரத்தை (data quality) உறுதி செய்யலாம். கெட்டர்கள் மற்றும் செட்டர்கள் ஒரு பொருளின் பண்புகள் மற்றும் முறைகளுக்கான எளிமையான தொடரியலை (syntax) வழங்குகின்றன. தரவு இணைப்பிற்குக் (Data Encapsulation) கெட்டர்கள் மற்றும் செட்டர்கள் பயன்படுத்தப்படுகின்றன.

கெட்டர்கள் மற்றும் செட்டர்களை ஏன் பயன்படுத்த வேண்டும்?

- இது எளிமையான தொடரியலைத் (syntax) தருகிறது
- இது பண்புகள் மற்றும் முறைகளுக்குச் சமமான தொடரியலை அனுமதிக்கிறது.
- இது சிறந்த தரவுத் தரத்தைப் பாதுகாக்க முடியும்.
- திரைமறைவில் (behind-the-scenes) விஷயங்களைச் செய்வதற்கு இது பயனுள்ளதாக இருக்கும். 

## ஜாவாஸ்கிரிப்ட் கெட்டர் (get முக்கியச்சொல் (keyword))
இந்த எடுத்துக்காட்டு மொழிப் பண்பின் (language property) மதிப்பைப் பெற ஒரு lang பண்பைப் பயன்படுத்துகிறது.

```sh

// Create an object:
const person = {
  firstName: "John",
  lastName: "Doe",
  language: "en",
  get lang() {
    return this.language;
  }
};

// Display data from the object using a getter:
document.getElementById("demo").innerHTML = person.lang;
```

## ஜாவாஸ்கிரிப்ட் செட்டர் (set முக்கியச்சொல் (keyword))
இந்த எடுத்துக்காட்டு மொழிப் பண்பின் மதிப்பை அமைக்க (set) ஒரு lang பண்பைப் பயன்படுத்துகிறது.

```sh
const person = {
  firstName: "John",
  lastName: "Doe",
  language: "",
  set lang(lang) {
    this.language = lang;
  }
};

// Set an object property using a setter:
person.lang = "en";

// Display data from the object:
document.getElementById("demo").innerHTML = person.language;
```

ஜாவாஸ்கிரிப்டில் உள்ள `getters` மற்றும் `setters` என்பவை பொருள் பண்புகளுக்கான (object properties) அணுகலைக் கட்டுப்படுத்தவும் கூடுதல் செயல்பாட்டை வழங்கவும் உதவும் சக்திவாய்ந்த கருவிகள் (tools) ஆகும். தனிப்பயன் தர்க்கத்துடன் (custom logic) பண்பு மதிப்புகளைப் (property values) மீட்டெடுக்கக் கெட்டர்கள் அனுமதிக்கின்றன, அதே சமயம் உள்வரும் மதிப்புகளைச் (incoming values) சரிபார்க்கவும் திருத்தவும் செட்டர்கள் உதவுகின்றன. கெட்டர்கள் மற்றும் செட்டர்களைப் பயன்படுத்துவதன் மூலம், நாம் தரவு இணைப்பைப் (data encapsulation) பராமரிக்கலாம், பாதுகாப்பை (security) மேம்படுத்தலாம் மற்றும் நமது பொருள்களின் ஒருமைப்பாட்டை (integrity) உறுதிப்படுத்தலாம்.
